# Working notes

The files in this directory are dated engineering notes written while each runtime change was made. They record
the contracts that were checked, the tests and the evidence observed at the time. Later changes often supersede
their status lines, so read the top-level README for the current state.

The notes were written during private development. They mention internal review, landing and cloud-host steps
(for example `scripts/land`, run deadlines and worker limits). That tooling is not part of this repository, and
some budget figures have been removed. Paths such as `.local/...` refer to ignored private storage on the
developer's machine. That storage holds game-derived files that are never published.
